# 周报网页与 PDF 呈现规范

本文件约束**公开成品**的结构、文字层级和视觉检查；[采编规范](EDITORIAL_GUIDE.md)决定收什么、如何核验，[维护手册](WEEKLY_OPERATIONS.md)决定如何入库与发布，[周报模板](ISSUE_TEMPLATE.md)提供逐期可复用的内容骨架。网页由 `scripts/build-site.mjs` 生成，PDF 由 `scripts/build-pdf.py` 从同一份 `site/current.json` 生成。变更模板时应同步检查两种输出，避免文档和代码分叉。

## 1. 不可变的发布约束

1. 网站只展示**当前一刊或预告**：正式刊写入 `site/index.html` 与 `site/current.json`，预告仅写首页并删除 `site/current.json`。根目录 `diarys/YYYY-MM-DD.pdf` 每期留档，不能放进 `docs/`。
2. 刊期是北京时间周一，统计窗口是前一周周一 00:00（含）至本周一 00:00（不含），页面可写成“上周一至周日”。不要把预告或未结束的一周写成已出版周报。
3. 网页顶部、主标题之前必须出现清楚可见的 **`AI生成`** 标识；PDF 首页标题附近也应说明 AI 参与生成。该标识在桌面和窄屏下都可见，不依赖悬停或展开。
4. 网页和 PDF **不展示编辑说明、内部核查记录、`claim_evidence_notes`**。公开 `site/current.json` 也不应带内部核查记录。请留意：若把原始条目 JSON 提交到公开仓库，其中的内部内容仍会公开。
5. 每篇论文都显示**第一作者及单位 → 所引版本的摘要原文 → 基于论文全文的主要贡献总结**，先后顺序不可颠倒。所有论文栏目，包括“论文速览”，执行同一规则。摘要原文不以 AI 翻译或缩写替代。
6. 非论文条目保留中英双语摘要；证据标签与标题中的措辞必须一致。企业单方消息的“机构宣称，未独立验证”要在标题附近可见。
7. 发布前检查网页和 PDF 的内容、日期、来源及 PDF 目标路径。视觉改版不得改变统计口径和证据含义。

## 2. 当前网页信息结构

从上到下排列：

1. 品牌导航：`RoboticsNews` 与“机器人学研究进展周报”。
2. 横向 AI 告知条：醒目的 `AI生成` 标签和“内容由 AI 辅助整理与总结；请以每条原始来源为准。”
3. 刊期首屏：`WEEKLY BRIEF · YYYY-MM-DD`、中文主标题、英文副标题、北京时间刊期、收录条目数、本期 PDF 链接。
4. 统计窗口说明：上周一 00:00 至周日 24:00 首次公开的信息；说明企业/机构单方内容的证据状态。
5. 有内容的栏目，依序为“本周重点 → 学术研究 → 工业与应用 → 生态动态 → 论文速览 → 补录与更正 → 其他进展”。空栏目不显示。默认条目按四项评分之和降序，同分按 ID 排列。
6. 页脚：站点名称与每周一更新说明。

`placement` 控制栏目，`category` 控制论文/非论文条目形式；二者不能互相代替。正式发布前尽量把 `unassigned` 处理成明确栏目。首页只显示本刊，不在页面混排历史刊。旧 PDF 留在 `diarys/`，当前首页 PDF 链接只指本刊。

### 2.1 论文条目

每张论文卡片按下列顺序：证据标签、最多三个主题标签、北京时间或原文日期、中文标题、英文标题、第一作者及全部单位、**“论文摘要原文 / Original abstract”**、原文摘要、**“基于全文的主要贡献 / Main contributions from the full paper”**、中文贡献总结、英文贡献总结、可选意义/局限、原始来源/论文全文/摘要原文链接；有代码和数据地址时网页也显示相应链接。

第一作者单位可有多个，按论文署名页顺序列出。原文摘要从所引版本完整复制到 `abstract_original`，网页允许自然换行并保留源文本中的换行；不能把中文概述当原文摘要。贡献总结写明方法、关键实验条件及结果、增量和边界，不重复粘贴摘要。论文速览的卡片不缩减这些必需信息；可通过选题数量控制篇幅。

### 2.2 非论文条目

证据标签、最多三个主题标签、日期、中文标题、英文标题、中文摘要、英文摘要、可选意义/局限、原始来源；代码或数据链接有值才显示。`official_claim` 应显示“机构宣称，未独立验证”。标题不得把公司预期或剪辑演示写成已经证实的规模部署。

### 2.3 预告与空状态

预告展示下一期周一 08:00、预定统计范围、“周报正在编制中”和 `AI生成`；**不显示假条目、正式刊条数或不存在的 PDF 链接**。没有已发布内容的空状态只是构建兜底，不应被当作完成的正式周报发布。

## 3. 当前网页视觉基线

| 项目 | 当前值或做法 | 改版约束 |
| --- | --- | --- |
| 内容宽度 | `.shell` 最大约 940 px，左右留白 | 窄屏不能水平滚动或截断长英文术语/URL |
| 主色 | 深蓝 `#18263a`，青蓝 `#16738a`，浅底 `#f7fafb` | 文本和链接保持足够清晰的对比，不靠颜色单独传达证据状态 |
| AI 告知 | 浅黄色横条、深色标签，位于导航下方 | 必须先于主标题和正文，可在移动端换行但不隐藏 |
| 首屏标题 | 大字中文标题，英文副标题与刊期元信息 | 保留中英标题层级；日期和 PDF 入口可直接找到 |
| 栏目与卡片 | 栏目标题左侧色条；白底边框卡片 | 一条一张卡，来源链接与正文分开，便于扫描 |
| 移动断点 | 约 640 px；标题、卡片内边距相应缩小 | 第一作者长单位、长摘要和长链接不得溢出视口 |
| 原文摘要 | 独立左侧竖线区块，`white-space: pre-wrap` | 保留原文换行；不要生成省略号或默认折叠摘要 |

样式源文件是 `site/style.css`。生成的 `site/index.html` 不是手工维护模板；持久的布局变更应改 `scripts/build-site.mjs` 与 CSS，再重新生成。当前页面为静态 HTML，不需要额外前端框架。

HTML 应保留语义层级（页面标题、栏目标题、卡片标题）、正确的中英文 `lang`、可访问的链接文字。外部链接在新标签页打开时使用 `rel="noopener noreferrer"`。若增加图像，必须核查来源、许可、替代文本和移动端尺寸；当前模板以文字为主，没有必需配图。

## 4. 当前 PDF 结构与排版基线

PDF 由同一期 `site/current.json` 生成，采用 **A4 纵向**。当前模板左右边距约 19 mm、上边距 20 mm、下边距 23 mm；页脚有 `RoboticsNews`、周报名称和页码。首页依序为英文眉题、中文主标题、英文副标题、刊期与条目数、`AI生成` 说明、分隔线、统计窗口，然后按网页相同的栏目顺序排正文。空栏目不显示。

当前字体为中文 `STSong-Light`、英文 `Helvetica`；中文标题约 22 pt、栏目标题约 14 pt、条目标题约 11.5 pt、正文约 9.3 pt，行距大于字号。此为**现有实现基线**，调整字号、字体或边距需以实际渲染效果为准。灰字不能淡到打印后无法阅读，链接颜色与正文要能区分。

PDF 论文条目包含：中英标题、证据状态与日期、第一作者及单位、摘要原文、中文和英文全文贡献总结、可选意义/局限、原始来源、摘要原文与论文全文链接。非论文条目包含中英摘要和原始来源。**目前 PDF 不像网页那样展示主题、代码和数据链接**；若这些信息被定为 PDF 必需字段，需同步修改 `scripts/build-pdf.py`，不能只更新本规范。

论文摘要可能跨页，允许自然分页；不要因整张卡片过长造成空白页、截断或溢出。栏目标题不得孤立在页末。中文、英文、数学符号及长链接都须检查实际渲染。当前 PDF 使用 ReportLab `Paragraph`，可能规范化原文中的换行和空白；`abstract_original` 数据仍须逐字保存，若某篇摘要的公式、缩进或换行具有实质意义，应先改进渲染并复查 PDF 再发布。PDF 内部不得出现编辑说明、核查记录、占位符、抓取日志或无效链接。

## 5. 网页和 PDF 的内容一致性

两种输出必须来自同一刊期数据，至少一致于：刊期与统计窗口、入选条目及栏目、标题、证据状态、第一作者单位、论文摘要原文、全文贡献总结、非论文中英摘要、意义和局限、原始来源。视觉形式可以不同，但不得在一端删去另一端用于判断可信度的关键限定语。公开 JSON 的条目数和页面条目数应一致。

链接处理：网页的 PDF 按钮应指向当前刊 `diarys/YYYY-MM-DD.pdf` 的可访问 URL；条目的原始链接应指向一手材料，不指向搜索结果。PDF 中的源链接应可点击或可辨认；超长 URL 不得压住其他文字。涉及论文摘要许可时先按 [采编规范](EDITORIAL_GUIDE.md) 核查，不能为了填满模板而复制无权公开的材料。

## 6. 每期视觉验收

在[维护手册的发布前检查](WEEKLY_OPERATIONS.md)之外，逐项查看：

- 桌面与约 375 px 宽窄屏：AI 告知、标题、日期、PDF 入口、长论文标题、长单位、原文摘要、长链接均完整可见；无横向滚动、遮挡或重叠。
- 论文和非论文各抽查至少一条；论文速览不能丢失第一作者单位、原文摘要和全文贡献总结。预印本与企业宣称的标签贴近标题。
- PDF 渲染检查首页、至少一页中段和末页；核对页眉/页脚、页码、栏目换页、中文字体、英文间距及长摘要分页。机器提取文字只用于辅助核对，不能代替目视检查。
- 对照 `site/current.json` 逐项核实网页/PDF 的刊期、条目数和关键字段；核查公开输出不含内部编辑说明与核查记录。
- 同一期重新生成 PDF 前确认是否为修订；旧 PDF 的保留或版本标注需符合[维护手册](WEEKLY_OPERATIONS.md)，不要无说明覆盖已发布内容。

只有完成内容核验、视觉验收并交给用户审阅后，才进入提交和发布步骤；**未经用户明确同意，不得 commit 或 push**。
