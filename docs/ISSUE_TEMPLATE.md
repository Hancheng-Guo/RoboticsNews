# 周报公开成品模板

这是一份**结构模板**，用于检查网页与 PDF 的内容是否完整；它不是构建脚本的输入文件，也不含真实新闻。每期实际页面由 `scripts/build-site.mjs` 生成，PDF 由 `scripts/build-pdf.py` 生成；字段取自数据库及 `site/current.json`。具体视觉规则见 [呈现规范](PRESENTATION_SPEC.md)，入选与核验规则见 [采编规范](EDITORIAL_GUIDE.md)。

方括号内容必须用真实、已核实的数据替换；不适用的可选段落才可删去。不要将本文件原样发布。按[呈现规范](PRESENTATION_SPEC.md)检查内容与结构；视觉查看不是必需的发布步骤。

## A. 正式周报首页

```text
RoboticsNews                                  机器人学研究进展周报

AI生成  内容由 AI 辅助整理与总结；请以每条所列来源为准。

WEEKLY BRIEF · [周一刊期 YYYY-MM-DD]
机器人学研究进展周报
Robotics Research & Industry · Weekly Brief

北京时间 [周一刊期] 发布 · [N] 条合格新增 · 查看本期 PDF
覆盖北京时间 [上周一] 00:00 至 [上周日] 24:00 首次公开的信息。
```

按实际内容依次呈现下列栏目，空栏目不显示：

1. 学术研究
2. 工业与应用
3. 生态动态
4. 论文速览
5. 补录与更正（当前构建器暂不支持统计窗口外事件，见维护手册）
6. 其他进展（正式出版前尽量避免 `unassigned`）

不固定各栏配额；按本周入选质量和重要性决定，目标约 10–15 条主要内容。
重点条目仍放在所属栏目，卡片右上角显示橙色三角标记。每个栏目按重点、评分、编辑重要性顺序排列；不另设“本周重点”。

## B. 论文条目模板

```text
[预印本 / 同行评审 / 其他准确证据标签]  [主题 1] [主题 2] [主题 3]  [北京时间或原文日期]

[中文标题]
[English title]

作者：[来源可确认的作者姓名，允许缩写；按署名顺序，标出第一作者与有证据的通讯作者；至少一人]
第一作者单位：[已核实时写“单位名，国家或地区”；否则写“不明确”]
通讯作者单位：[逐位列出“作者：单位名，国家或地区”；无明确通讯作者标记时写“论文未注明通讯作者”]

摘要原文可转载并可公开翻译时（先按采编规范逐平台核验；arXiv/OpenReview 公开摘要元数据、PMLR、符合条件的 ACL Anthology 等有明确路径）：
论文摘要原文 / Original abstract：[所引版本逐字核对的摘要]
摘要中文翻译：[原文非中文时填写忠实译文]
摘要署名与许可：[作者、出处、许可链接及翻译/排版说明]

检索其他开放版本后仍无法确认原文及译文公开依据时：
论文内容转述 / Paraphrase：[依据可访问来源写中英转述，不复制摘要或冒充翻译]

意义：[有具体依据时填写]
局限：[已知局限或尚未披露的信息]

论文来源：[优先论文版本页 URL；找不到时填转载页并显著标记]
摘要原文：[展示原文时才附摘要来源 URL]
单位依据：[单位已核实时才附证明该单位的 URL]
通讯作者依据：[逐位附明确标记及对应单位的来源 URL]
代码/数据：[已开放且已核对时，网页显示对应链接]
```

“论文速览”也使用此模板，不能只保留标题。`summary_zh`、`summary_en` 仍是数据库必填字段；arXiv 投稿摘要属于 CC0 元数据，优先展示原文及中文翻译。其他来源确实无法确认摘要转载依据时才用中英转述。不撰写全文贡献总结。单位不明确或缺少论文一手链接时按上方规则标注，不因此排除；日期或作者查证后仍完全缺失时不收录。

## C. 非论文条目模板

```text
[证据标签；机构单方消息为“机构宣称，未独立验证”]  [主题标签]  [日期]

[中文标题；宣称须明确归属]
[English title]

[中文摘要：新事实、证据、适用条件]
[English summary: same facts and boundaries]

意义：[有具体依据时填写]
局限：[已知局限或尚未披露的信息]

原始来源：[企业/客户/监管/项目官方 URL]
代码/数据：[有值且已核对时，网页显示对应链接]
```

## D. PDF 首页与续页

PDF 首页沿用网页的刊期、统计窗口、条目数和 `AI生成` 告知；栏目色条、白底卡片标题区、主题及证据标签、重点橙色角标与网页对应。栏目和条目顺序相同。每页页脚显示 `RoboticsNews`、周报名称与页码；论文长摘要可跨页。来源、摘要和单位依据链接可点击。详情见[呈现规范](PRESENTATION_SPEC.md)。

## E. 预告页模板

```text
RoboticsNews
AI生成  内容由 AI 辅助整理与总结；请以所列来源为准。

WEEKLY BRIEF · COMING SOON
机器人学研究进展周报

下期：北京时间 [下一个周一] 08:00
覆盖：[上周一] 至 [上周日]
周报正在编制中。完整统计窗口结束并完成核验后，本页将更新为本期内容和 PDF。
```

预告没有正式条目数、`site/current.json` 或 PDF 链接。正文与 PDF 均**不得**展示编辑说明、内部核查记录和占位符。
